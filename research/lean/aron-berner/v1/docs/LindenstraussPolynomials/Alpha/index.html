The step sizes

The perturbations of the construction use the step sizes \alpha_k=a^{2^k} for a fixed a\in(0,1), so that \alpha_{k+1}=\alpha_k^2; this identity is used essentially in the inductive step. The module proves the tail estimates (eq:tails) and the product estimate (eq:product). Indices start at 0: \alpha_0=a is the article's \alpha_1.
