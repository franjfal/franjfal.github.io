# Calculus Cases — shared assets

`calculus-cases.css` is the shared stylesheet of every activity page of the book *Calculus Casebook*
(Ciudad Delta / Delta City, the popcorn box, the calculus duel, and future cases).
The full standard (header/feature images, page structure, generator block, PDF house style and data rules)
is documented in the book repository: `ESTANDAR_WEB_ACTIVIDADES.md`.
